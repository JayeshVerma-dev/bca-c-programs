## 🛠 How to Run the Programs

### 🔹 **Running With GCC (Recommended — Modern Compilers)**

If you are using GCC (VSCode, Windows, Linux, macOS):

**Step 1: Compile**
gcc filename.c -o output

**Step 2: Run**

Windows:
output.exe

Linux/macOS:
./output
